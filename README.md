# 眨眼报警助手 (Blink Alarm)

面向渐冻症（ALS）患者的 Windows 桌面软件：用摄像头监测眼睛，**连续眨眼 N 次（默认 5 次）即触发声响报警**，并可选联动 Home Assistant / 米家等外部设备。
界面采用大字体、大按钮，方便只能通过**眼控仪**操作的患者进行设置。

## 零、不懂编程？用 GitHub 自动编译成 exe（推荐）

只要你有 GitHub 账号，**完全不用在电脑上安装 Python**。让 GitHub 的服务器免费帮你打包成一个 `BlinkAlarm.exe`，你下载后双击即可运行。

### 步骤

1. **新建仓库**：登录 GitHub → 右上角 `+` → `New repository` → 填个名字（如 `blink-alarm`）→ 选 `Private`（私有）→ 点 `Create repository`。

2. **上传代码**：进入新仓库 → 点 `uploading an existing file` → 把本项目**所有文件和文件夹**（包括隐藏的 `.github` 文件夹）一起拖进去 → 点 `Commit changes`。
   - 小技巧：用 **GitHub Desktop** 软件（可下载）把文件夹“Add existing repository → publish”，会自动包含 `.github` 文件夹，比网页拖拽更省事。

3. **等待自动编译**：上传后 GitHub 会自动开始编译。点仓库顶部的 **Actions** 标签，会看到一个正在运行的任务，黄色转圈表示进行中，变成绿色 ✅ 表示成功（大约几分钟到十几分钟）。

4. **下载 exe**：点进那个成功的任务 → 页面底部 **Artifacts** 区域 → 点 **BlinkAlarm-Windows** 下载（是一个 zip，解压后里面就是 `BlinkAlarm.exe`）。

5. **运行**：把 `BlinkAlarm.exe` 放到电脑任意文件夹，**双击运行**。首次打开稍慢（要解压内置组件），属正常现象。

> 想要更正式的下载方式（如发给别人）：在仓库里点 `Releases → Draft a new release`，填一个 tag 如 `v1.0`，发布后 GitHub 会再次编译并把 exe 作为附件，任何人可下载。

### 常见问题

- 看不到 Actions 或没有权限：确认上传时 `.github/workflows/build.yml` 已包含在内（文件夹名字前面带点，可能被系统隐藏，注意别漏掉）。
- 编译失败（红色 ❌）：把红色日志截图发我，我来修。
- 杀毒软件报警：属于 PyInstaller 打包 exe 的常见误报，添加信任即可。

## 一、运行环境（本地开发用，普通用户可跳过）

- 操作系统：Windows 10 / 11
- Python：**3.9 ~ 3.12**（推荐 3.10 / 3.11，mediapipe 对 3.13+ 支持有限）
- 摄像头：笔记本内置摄像头或外接 USB 摄像头
- 音响：电脑音响，或外部联动设备

## 二、安装

方式一（推荐，Windows）：
1. 安装 Python 时务必勾选 **Add Python to PATH**。
2. 双击 **`安装依赖.bat`**，等待安装完成。
3. 双击 **`启动程序.bat`** 打开软件。

方式二（命令行）：
```
pip install -r requirements.txt
python main.py
```

## 三、使用

1. 选择「摄像头编号」（一般内置摄像头是 0，外接 USB 摄像头尝试 1、2…）。
2. 点击绿色 **▶ 开始监测**。预览画面会显示眼睛关键点和 EAR 值：
   - 绿色 = 睁眼，红色 = 闭眼。
3. 正对摄像头，连续眨眼（默认 5 次，累计时间窗口 2 秒内），即触发报警。
4. 顶部状态条实时显示「连续眨眼 X / 5」；触发时变红并显示「🔔 已触发报警！」。

### 关键设置

| 设置项 | 说明 |
| --- | --- |
| 灵敏度 | 0~100。越高越容易判定为闭眼（对应闭眼阈值 EAR 越大）。画面下方会显示当前 EAR 阈值，便于对照调试。 |
| 连续眨眼次数 | 触发报警所需的连续眨眼次数（默认 5）。 |
| 累计时间窗口 | 多少次眨眼需在此时间内连续完成，否则计数清零。 |
| 报警冷却 | 触发一次后的静默时间，避免连续触发。 |
| 最少/最长闭眼帧数 | 高级防抖参数。闭眼帧数过少（抖动）或过长（闭眼休息/睡着）都不算一次眨眼。 |

设置完成后点 **保存设置**，写入同目录 `config.json`，下次启动自动读取。

## 四、声响报警

- 默认播放内置双音警笛声，可通过「响铃时长」调整。
- 如需自定义声音，点「选择 wav」指定一个 `.wav` 文件。
- 点「测试声音」可试听。

## 五、外部设备联动（Home Assistant / 米家）

软件在触发时向指定地址发送 HTTP 请求（Webhook）。

1. 勾选「启用外部报警」。
2. 填写地址，例如 Home Assistant 的 Webhook：
   ```
   http://192.168.1.10:8123/api/webhook/blink_alarm
   ```
3. 选择方法 `POST`，载荷为 JSON，例如：
   ```json
   {"event": "blink_alarm", "target_blinks": 5}
   ```
4. 点「测试外部报警」验证连通性。

在 Home Assistant 中配置自动化（automation）监听该 webhook，即可联动灯光、蜂鸣器、手机通知等。
米家没有官方开放 Webhook，可通过 Home Assistant 的米家集成，或用米家自动化配合中转服务来实现，思路相同。

## 七、常见问题

- **打开摄像头失败**：换「摄像头编号」重试；关闭占用摄像头的其它软件（微信、钉钉、Zoom 等）。
- **误触发频繁**：降低灵敏度；或在光线稳定、背景整洁的环境下使用。
- **眨眼识别不到**：提高灵敏度；确保面部光照充足、正对摄像头、眼睛可见（避免强逆光、戴深色眼镜）。
- **mediapipe 安装失败**：确认 Python 版本为 3.9~3.12；可先执行 `pip install --upgrade pip`。
